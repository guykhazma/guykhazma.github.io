# guykhazma.github.io

Personal website of Guy Khazma, served by GitHub Pages at https://guykhazma.github.io.

Built with Jekyll on the [AcademicPages](https://github.com/academicpages/academicpages.github.io) theme (a fork of [Minimal Mistakes](https://github.com/mmistakes/minimal-mistakes)).

## Running locally

```bash
bundle install
bundle exec jekyll serve
```

Then open http://localhost:4000.
